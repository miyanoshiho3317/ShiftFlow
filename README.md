# ShiftFlow 倒班日历

一个用于电厂五班三运转人员的本地排班日历工具。它会按照固定循环生成班表，并导出可导入 Apple Calendar 的 `.ics` 文件。

## 排班规律

默认规则为 6 天一个循环：

| 循环日 | 班次 | 时间 |
| --- | --- | --- |
| 第 1 天 | 白班 | 08:00–16:00 |
| 第 2 天 | 夜班 | 00:00–08:00 |
| 第 3 天 | 休息 | — |
| 第 4 天 | 中班 | 16:00–24:00 |
| 第 5 天 | 休息 | — |
| 第 6 天 | 休息 | — |

页面默认以 **2026-08-11 为中班** 作为锚点。你可以将“已知日期”和“当天班次”改为实际信息，点击“更新日历”后即可重新推算。

> 夜班按前一日 24:00（即当天 00:00）至当天 08:00 处理，全部使用 24 小时制。

## 使用方法

### 在电脑上离线使用

下载或复制整个项目文件夹，双击 `index.html`，即可在浏览器中打开。

请保持以下文件位于同一文件夹：

```text
index.html
styles.css
app.js
manifest.webmanifest
sw.js
```

排班计算和 `.ics` 导出均在本机浏览器中完成，不会上传数据。

### 导出到 Apple Calendar

1. 设置排班锚点和生成年数。
2. 点击“导出 .ics 日历”。
3. 在 Mac 上双击下载的文件并选择导入日历；在 iPhone 上打开下载文件后，按系统提示添加到日历。

休息日不会被写入 `.ics`，导出的事件仅包含白班、夜班和中班。

## 手机与 iPhone

页面已针对手机屏幕优化：日期格底部的细色带显示 24 小时中的实际班次区间，夜班在左侧、白班居中、中班在右侧。

若想在 iPhone 上像应用一样使用，建议把项目发布到 HTTPS 网站后：

1. 用 Safari 打开网站。
2. 点击“分享”按钮。
3. 选择“添加到主屏幕”。

首次访问后，网站会缓存必要文件；之后在网络不可用时仍可打开已缓存的页面。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，例如 `shiftflow`。
2. 上传本项目的全部文件到仓库根目录。
3. 打开仓库的 **Settings** → **Pages**。
4. 在 **Build and deployment** 中选择从分支部署，分支选择 `main`，目录选择 `/(root)`，然后保存。
5. 等待 GitHub 发布完成，访问提示中的网址。

通常网址为：

```text
https://你的用户名.github.io/shiftflow/
```

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与移动端元信息 |
| `styles.css` | 视觉样式、响应式布局和 24 小时时间轴 |
| `app.js` | 排班计算、月历渲染和 `.ics` 导出 |
| `manifest.webmanifest` | 添加到主屏幕时使用的网页应用信息 |
| `sw.js` | 已发布网站的离线缓存 |

## 隐私

本工具不包含账号、服务器或数据收集功能。所有输入仅在你的设备浏览器内使用。
