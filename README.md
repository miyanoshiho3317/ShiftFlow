# ShiftFlow 倒班日历

ShiftFlow 是一个面向电厂五班三运转人员的排班日历工具。它会按照固定循环生成班表、支持单日调班，并导出可导入 Apple Calendar 的 `.ics` 文件。

在线使用：<https://miyanoshiho3317.github.io/ShiftFlow/>

## 功能概览

- **自动排班**：按白班、夜班、休息、中班、休息、休息的 6 天循环生成未来 1–10 年班表。
- **24 小时时间轴**：日期格底部用细色带显示班次实际覆盖区间；夜班在 00:00–08:00、白班在 08:00–16:00、中班在 16:00–24:00。
- **班次配色**：可用圆环色盘或 `#RRGGBB` 色号调整白班、夜班、中班和休息日颜色；设置保存在当前设备。
- **排班统计**：显示所选年限的总计，以及随月历月份切换而更新的当月班次计数。
- **节假日提醒**：日历会标记已收录的官方节假日与调休补班日；提醒不会修改倒班规律。
- **单日调班**：点击日期即可临时改为白班、夜班、中班或休息，并可随时恢复原始循环。
- **ICS 导出**：一键导出 Apple Calendar 可识别的 `.ics` 文件，单日调班会同步写入导出结果。
- **手机适配**：适配 iPhone Safari；发布到 HTTPS 后可添加到主屏幕，并缓存页面以便后续离线打开。

> 所有排班计算、配色和调班记录都仅保存在当前设备浏览器中，不会上传。

## 排班规律

默认规则为 6 天一个循环：

| 循环日 | 班次 | 时间 |
| --- | --- | --- |
| 第 1 天 | 白班 | 08:00–16:00 |
| 第 2 天 | 夜班 | 00:00–08:00 |
| 第 3 天 | 休息 | — |
| 第 4 天 | 中班 | 16:00–24:00 |
| 第 5 天 | 休息 | — |
| 第 6 天 | 休息 | — |

页面默认以 **2026-08-11 为中班** 作为锚点。你可以将“已知日期”和“当天班次”改为实际信息，点击“更新日历”后即可重新推算。

> 夜班按前一日 24:00（即当天 00:00）至当天 08:00 处理，全部使用 24 小时制。

## 使用方法

### 在电脑上离线使用

下载或复制整个项目文件夹，双击 `index.html`，即可在浏览器中打开。

请保持以下文件位于同一文件夹：

```text
index.html
styles.css
app.js
manifest.webmanifest
sw.js
```

排班计算和 `.ics` 导出均在本机浏览器中完成，不会上传数据。

### 生成与调整班表

1. 填写任意一个已知日期和当天实际班次，点击“更新日历”。
2. 使用左右箭头浏览月份；统计条会同时显示多年总计和当月计次。
3. 如需调班，点击对应日期，在出现的“单日调班”栏中重新选择班次。
4. 单日调班会立即刷新月历、统计和后续 `.ics` 导出；它只影响当天，不会推移之后的循环。
5. 如需撤销当天调整，点击“恢复原始排班”。

> 浏览器不能静默覆盖已经下载的文件。重新导出时会生成同名新文件，浏览器可能自动加上 `(1)`；导入新版前，建议先删除 Apple Calendar 中旧的“倒班”日历，避免重复事件。

### 导出到 Apple Calendar

1. 设置排班锚点和生成年数。
2. 点击“导出 .ics 日历”。
3. 在 Mac 上双击下载的文件并选择导入日历；在 iPhone 上打开下载文件后，按系统提示添加到日历。

休息日不会被写入 `.ics`，导出的事件仅包含白班、夜班和中班。

## 手机与 iPhone

页面已针对手机屏幕优化：日期格底部的细色带显示 24 小时中的实际班次区间，夜班在左侧、白班居中、中班在右侧。

若想在 iPhone 上像应用一样使用，建议把项目发布到 HTTPS 网站后：

1. 用 Safari 打开网站。
2. 点击“分享”按钮。
3. 选择“添加到主屏幕”。

首次访问后，网站会缓存必要文件；之后在网络不可用时仍可打开已缓存的页面。

在中国大陆，GitHub Pages 的连通性可能受网络环境影响；若无法直接打开，可改用适合团队网络环境的静态网站托管服务。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，例如 `shiftflow`。
2. 上传本项目的全部文件到仓库根目录。
3. 打开仓库的 **Settings** → **Pages**。
4. 在 **Build and deployment** 中选择从分支部署，分支选择 `main`，目录选择 `/(root)`，然后保存。
5. 等待 GitHub 发布完成，访问提示中的网址。

通常网址为：

```text
https://你的用户名.github.io/shiftflow/
```

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与移动端元信息 |
| `styles.css` | 视觉样式、响应式布局和 24 小时时间轴 |
| `app.js` | 排班计算、月历渲染和 `.ics` 导出 |
| `manifest.webmanifest` | 添加到主屏幕时使用的网页应用信息 |
| `sw.js` | 已发布网站的离线缓存 |

## 节假日数据说明

当前内置 2026 年国务院办公厅公布的元旦、春节、清明、劳动节、端午、中秋、国庆节放假与调休日期。由于具体调休安排按年度公布，未来年份会在官方通知发布后更新；节假日标签仅作提醒，不会替代或改变倒班规则。
